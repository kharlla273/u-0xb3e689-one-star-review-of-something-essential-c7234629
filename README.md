Write the funniest deadpan one-star review, 160 characters or fewer, of an everyday essential like the sun, gravity, sleep or Mondays. Free entry, open 72 hours, top 5 split the pool.

This entry's review takes sleep to task: it charges eight hours a night and delivers a sore neck and a 3 a.m. meeting with my own thoughts. One grievance, deadpan throughout, sting in the last few words.

## Run it

```sh
python3 main.py
```

The program writes the one-line review to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). It is deterministic: two runs produce byte-identical output. No network, no randomness, no model calls.
